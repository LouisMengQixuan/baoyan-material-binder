# 保研网申装订引擎（Baoyan Material Binder）

一个面向保研夏令营、预推免、九推网申场景的本地化材料整理工具。它可以根据招生通知识别材料清单，按材料类型归档 PDF / 图片文件，并一键生成单一 PDF 或 ZIP 压缩包。

## 功能特点

- 粘贴招生通知后，自动识别常见材料项：成绩单、排名证明、英语成绩单、身份证、学生证、获奖证书、科研材料、推荐信、个人陈述、简历、研究计划等。
- 支持拖拽上传 PDF、JPG、PNG。
- 支持材料夹内部文件排序。
- 支持总章节顺序调整。
- 支持自动跳过空材料夹。
- 支持自定义命名规则，例如：`{学校}+{姓名}+夏令营报名`。
- 支持导出单一 PDF 或 ZIP 压缩包。
- 对部分电子证明类 PDF 提供兜底兼容：当直接复制 PDF 页面失败时，会尝试把 PDF 页面渲染为图片后写入最终 PDF。
- 全部处理在浏览器本地完成，不上传用户文件。

## 在线部署到 GitHub Pages

1. 新建一个 GitHub 仓库，例如 `baoyan-material-binder`。
2. 将本项目中的全部文件上传到仓库根目录。
3. 进入仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. 保存后等待 GitHub Pages 部署完成。
6. 部署完成后，打开 GitHub Pages 给出的访问链接即可使用。

## 本地使用

直接双击打开 `index.html` 即可。首次使用需要联网加载前端依赖库。

## 依赖说明

本项目为纯前端静态网页，依赖 CDN 加载：

- `pdf-lib`：PDF 创建与合并
- `JSZip`：ZIP 压缩包生成
- `PDF.js`：异常 PDF 的页面渲染兜底

如果希望完全离线使用，可以把上述依赖下载到本地，并修改 `index.html` 中的 CDN 引用。

## 常见问题

### 1. 某个 PDF 生成失败怎么办？

优先看页面底部的运行日志，定位失败文件。如果是四六级、雅思、学信网、电子签章类 PDF，可以尝试：

- 用浏览器打开原 PDF；
- 选择“打印”；
- 目标打印机选择“另存为 PDF”；
- 再上传重新生成。

### 2. Word、Excel、PPT 能直接上传吗？

不能。请先另存为 PDF，再上传。

### 3. 文件会不会上传到服务器？

不会。该工具是纯前端实现，文件只在浏览器本地处理。
